===========================================================
=               2. INSTALLATION INSTRUCTIONS              =
===========================================================

!!! Remember to always make a backup before installing any mods !!!

a. STEAM
-----------------------------------------------------------
1. Download the mod files and extract them to a temporary folder.
2. Open Steam and go to your Library.
3. Right-click the game you want to mod and select 'Properties'.
4. In the 'Properties' window, select the 'Local Files' tab.
5. Click on 'Browse Local Files' to open the game directory.
6. Copy the extracted mod files into the game directory, replacing the files if asked.

-----------------------------------------------------------

b. LESTA / WARGAMING GAME CENTER
-----------------------------------------------------------
1. Download the mod files and extract them to a temporary folder.
2. Open the Game Center and select Tanks Blitz / World of Tanks Blitz.
3. Click on 'Game Settings' and select 'Show in Folder' to open the game directory.
4. Copy the extracted mod files into the game directory, replacing the files if asked.
